# Huffman CompDecomp -- ENSEEIHT 1SN Imperative Programming course

This project implements the Huffman coding compression algorithm in Ada. The goal of this application is to compress files completely losslessly, generating a custom `.hff` binary file with a reduced storage footprint and decompress it back to its exact original state.

The core logic handles reading the file occurrences, dynamically building a Huffman Tree, generating an infixed route map for tree rebuilding, and writing out compressed binary codes. The decompression tool uses these artifacts bundled within the file to perform the reverse operation seamlessly.

## Directory Structure

*   **/src/** - Contains all Ada source code and shell testing scripts (`demo_*.bash`).
    *   `compression.adb` / `decompression.adb`: The main entry modules.
    *   `arbre`, `lca`, `octet`: Utility structures for parsing binary sequences, linked list handling, and binary tree representations.
*   **/doc/** - Contains the formal project report (`rapport_1.txt`) and other documentation.
*   **/livrables/** - Expected delivery output folder (e.g., PDF reports).
*   **/tests/** and **/results/** - Source text files for testing along with their dynamically generated corresponding `.hff` outputs.

## How to Use

*(Note: Ensure you have an Ada compiler installed, such as GNAT, to compile the project if not already compiled).*

### Compilation
Navigate to the `src` directory and compile the main project executables:
```bash
cd src
gnatmake compression.adb
gnatmake decompression.adb
```

## Compression
To compress a given file, run the `compression` executable. By default, it generates a `.hff` extension file in the same directory. You can optionally use the `-s` (silent) or `-b` (verbose/bavard) arguments:

```bash
# Verbose mode (Default, prints the Huffman Tree and details)
./compression -b file.txt
# or 
./compression --bavard file.txt

# Silent mode
./compression -s file.txt
# or
./compression --silencieux file.txt
```

## Decompression
To decompress a `.hff` file (generated by the compression step above), run the `decompression` executable. Similar to the compression app, it comes with silent and text-verbose modes:

```bash
# Decompressing with verbose output
./decompression -b file.txt.hff

# Decompressing silently
./decompression -s file.txt.hff
```
